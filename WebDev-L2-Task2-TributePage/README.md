A visually engaging tribute page built with HTML5 and CSS3 for the Oasis Infobyte Web Development and Designing internship.

## Objective

Design and build a visually engaging tribute page dedicated to a historical figure, scientist, artist, or public figure you admire.

## Tech Stack

- HTML5
- CSS3
- JavaScript optional

## Feature Checklist

- [ ] Page title with the subject's name and a one-line tagline
- [ ] A prominent image (use a royalty-free image sourced from Unsplash or Wikimedia Commons)
- [ ] A biography or tribute section with at least 3–4 paragraphs of original written content
- [ ] A timeline or key achievements section (ordered list or styled cards)
- [ ] A quote block with a notable quote, styled distinctly
- [ ] At least 2 different background colours used across sections
- [ ] At least 2 font styles explored (e.g., serif for headings, sans-serif for body)
- [ ] Responsive layout

## Planned Approach

- Choose a subject and gather factual references from Wikipedia or Britannica; paraphrase all content.
- Source a royalty-free image from Unsplash or Wikimedia Commons and include attribution.
- Build the page with semantic HTML sections and a responsive CSS layout.
- Use a distinct colour palette and typography pairing.
- Keep the page static unless a small JavaScript enhancement adds value.

## Open Decisions

- Tribute subject
- Image source and attribution
- Colour palette and font pairing
